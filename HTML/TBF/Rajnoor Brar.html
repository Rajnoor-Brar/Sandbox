HTML
HTML is the base of a web-page. It consist of various simple codes known as 'Tags'.Tags determine the type and basic properties of an element in a web-page.
Text and Graphics like Audio ,Videos and Images etc are added using tags which may contain or modify data.
In short ,HTML form the basic structure and is the back-bone of the web-page
CSS
CSS (Cascading StyleSheet) is used for formating text and graphics
It can be used to set large variety of the settings including:-
  • Text Shadows
  • Custom Colors
  • BackGround Colors | Image
  • Different margins for each Element
JavaScript

JavaScript is programming language for HTML which can be used change Attributes of element , format styles in CSS ,create new elements...on the specified events like Button Click or others pre-timed programmed events

An another , advanced yet simple , form of javascript known as jQuery can also be used to give HTML a variety of dynamic features which JavaScript can't.These events can even be triggered on events like on scrolling the page etc.
